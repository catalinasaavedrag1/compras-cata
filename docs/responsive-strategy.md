# Responsive Strategy

## Desktop

- Sidebar persistente con modulos principales.
- Top navigation contextual.
- Tablas compactas con maximo 8 columnas principales.
- Drawers para detalle y decisiones.

## Tablet

- Reducir columnas.
- Priorizar filtros principales.
- Mantener acciones visibles cerca del contenido.

## Mobile

- No comprimir tablas de escritorio.
- Usar tarjetas, listas, accordions y bottom sheets.
- Bottom nav con accesos principales.
- Menu completo como drawer.
- CTA principal full width cuando sea accion de flujo.

## Accesibilidad

- Targets tactiles de al menos 40px cuando sea posible.
- Foco visible.
- Dialogos con cierre por Escape y foco inicial.
- Texto visible en estados criticos.
- No depender solo del color.

## Estados

- Empty states deben explicar que significa no tener datos.
- Loading debe usar skeleton por bloque.
- Error parcial debe afectar solo la seccion que fallo.
